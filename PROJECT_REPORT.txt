1. EXECUTIVE SUMMARY & ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------
PackPal is an AI-enhanced travel packing assistant, weather-aware itinerary
planner, and group expense tracker (TripSplit) built for Hacktoberfest 2026.
It balances local AI intelligence (Ollama + Gemma 2) with pure deterministic 
TypeScript fallbacks, ensuring 100% functionality even when offline or when
external APIs are unconfigured.

Architectural Flow:
  User Request / Natural Language Prompt
        │
        ▼
  Next.js 16 App Router UI Pages
  (Landing, Onboarding, Dashboard, Packing, Itinerary, TripSplit, Members)
        │
        ▼
  Next.js API Route Layer
        │
        ├── 1. SerpApi ─────────────► Live Google Search & Weather Context
        │
        ├── 2. AI Layer (Ollama) ───► Gemma 2 Local LLM Inference
        │         │                   (Structured Zod schemas for packing,
        │         │                    expenses, optimization & trip changes)
        │         ▼
        │     Smart Fallback Engine ──► Pure TypeScript deterministic logic
        │                               (Activates seamlessly if Ollama is offline)
        │
        ├── 3. ElevenLabs ──────────► Voice Summary / Text-to-Speech Audio Stream
        │
        ├── 4. MongoDB ─────────────► Trip & Packing Records Persistence
        │
        ├── 5. Sentry ──────────────► Error Monitoring & Telemetry
        │
        └── 6. DevRelay MCP ────────► Development Evidence & Session Preservation

D. Third-Party API Keys Integration Guide
   -----------------------------------------------------------------------------
   All keys should be configured in `packpal/.env.local`. Here is how to obtain 
   and configure each integration:

   1. SerpApi (Live Destination Weather & Travel Highlights)
      - Purpose: Live Google search for real-time forecast and destination tips.
      - How to obtain:
        1. Sign up at https://serpapi.com/
        2. Copy your private API key from the SerpApi dashboard.
      - Config in `.env.local`:
        SERPAPI_API_KEY=your_actual_serpapi_key_here

   2. MongoDB Atlas (Cloud Database Persistence)
      - Purpose: Persisting packing lists and trips beyond browser localStorage.
      - How to obtain:
        1. Create a free M0 cluster at https://www.mongodb.com/cloud/atlas
        2. Create a Database User and whitelist your IP (or 0.0.0.0/0).
        3. Click "Connect" -> "Drivers" (Node.js) and copy the connection URI.
      - Config in `.env.local`:
        MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/?retryWrites=true&w=majority
        MONGODB_DB=packpal

   3. ElevenLabs (Voice Summary & Audio Briefings)
      - Purpose: High-fidelity natural voice packing briefings.
      - How to obtain:
        1. Sign up at https://elevenlabs.io/
        2. Go to Profile Settings -> API Keys -> Create API Key.
        3. Choose a voice (e.g., "Rachel" voice ID: `21m00Tcm4TlvDq8ikWAM`).
      - Config in `.env.local`:
        ELEVENLABS_API_KEY=your_elevenlabs_api_key
        ELEVENLABS_VOICE_ID=21m00Tcm4TlvDq8ikWAM

   4. Sentry (Error Telemetry & Performance Monitoring)
      - Purpose: Catching production runtime exceptions and logging API telemetry.
      - How to obtain:
        1. Sign up at https://sentry.io/
        2. Create a Next.js project and copy the DSN URL.
      - Config in `.env.local`:
        SENTRY_DSN=https://your_key@sentry.io/your_project_id
        NEXT_PUBLIC_SENTRY_DSN=https://your_key@sentry.io/your_project_id

   5. Ollama & Gemma 2 (Local LLM Inference)
      - Purpose: 100% private, local AI generation with no API costs.
      - How to install:
        1. Download Ollama from https://ollama.com/download
        2. Open terminal and pull the Gemma 2 model:
           ollama run gemma2
        3. Ensure Ollama service is active at `http://localhost:11434`.
      - Config in `.env.local`:
        OLLAMA_BASE_URL=http://localhost:11434
        OLLAMA_MODEL=gemma2:latest
